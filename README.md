# Модуль геопланирования

## Описание

Модуль предназначен для автоматического распределения географических точек (клиентов, магазинов, объектов обслуживания) по дням месяца и формирования кластеров, пригодных для ежедневного обхода.

**Ключевые особенности:**
- Равномерное распределение визитов по дням месяца.
- Гибкая кластеризация с использованием DBSCAN и принудительным разбиением кластеров для соблюдения лимита точек на день (8–12).
- Построение оптимальных маршрутов внутри кластера методом ближайшего соседа.
- Интерактивная визуализация на карте с отображением кластеров, маршрутов и точек.
- Подробная статистика и графический анализ результатов.
- Поддержка командной строки.

## Выбор алгоритмов

- **Кластеризация (DBSCAN):** Выбран за его способность:
    - Не требовать заранее заданного количества кластеров.
    - Эффективно работать с "шумом" (точками, которые не входят ни в один кластер).
    - Находить кластеры произвольной формы.
- **Разбиение кластеров (KMeans + рекурсия):** Используется для принудительного разбиения кластеров, которые превышают заданный лимит `max_cluster_size` (8-12 точек). Это гарантирует, что каждый кластер может быть обслужен за один день.
- **Построение маршрута (Nearest Neighbor):** Простой и эффективный эвристический алгоритм для TSP. Начинает с центральной точки кластера и последовательно добавляет ближайшую непосещенную точку.

## Командная строка для запуска через терминал (на ios)

Аргументы:
* input_file (обязательный): Путь к CSV-файлу с данными.
* -o, --output: Путь для сохранения результатов (по умолчанию: results.csv).
* -e, --eps: Радиус кластеризации в км (по умолчанию: 0.5).
* -m, --min-samples: Минимальное количество точек для формирования кластера (по умолчанию: 2).
* -M, --max-cluster-size: Максимальный размер кластера (по умолчанию: 10).
* -r, --random-seed: Seed для воспроизводимости (по умолчанию: 42).
* --map: Сохранить карту в HTML файл (по умолчанию: map.html).
* --no-save: Не сохранять результаты.


   ```bash
    python src/main.py data/data.csv -e 0.5 -M 10 -o results.csv --map map.html
